# ⏰ Reminder Bot

[![CI](https://github.com/proxende1/reminder-bot/actions/workflows/ci.yml/badge.svg)](https://github.com/proxende1/reminder-bot/actions/workflows/ci.yml)

![aiogram](https://img.shields.io/badge/aiogram-3.x-2CA5E0)
![License](https://img.shields.io/badge/license-MIT-green)

Telegram-бот-напоминалка, который понимает обычную русскую речь. Никаких форм и календарей: пишете «завтра в 10:00 позвонить маме», и бот напомнит.

## Возможности

- **Естественный язык.** Относительное время, абсолютное, дни недели, даты, «утра/вечера»
- **Повторы:** каждый день, по будням, по конкретным дням недели
- **Кнопки под напоминанием:** «+10 мин», «+1 час», «Завтра», «Готово»
- **Список с удалением:** `/list` с кнопками удаления
- **Напоминания не теряются при перезапуске.** Всё хранится в SQLite, а пропущенные за время простоя придут сразу после старта
- **Корректная работа с часовыми поясами,** включая переход на летнее и зимнее время

## Что понимает бот

| Пример | Когда сработает |
|---|---|
| `через 15 минут проверить духовку` | через 15 минут |
| `через 1ч 30м выйти из дома` | через полтора часа |
| `через полчаса чай` | через 30 минут |
| `10m размяться` | через 10 минут |
| `в 18:30 забрать посылку` | сегодня в 18:30 (или завтра, если время прошло) |
| `завтра в 10:00 позвонить маме` | завтра в 10:00 |
| `в 7 вечера тренировка` | в 19:00 |
| `в пятницу в 19:00 кино` | ближайшая пятница |
| `25.12 в 9:00 поздравить коллег` | 25 декабря |
| `каждый день в 9:00 витамины` | ежедневно |
| `по будням в 8:30 стендап` | пн–пт |
| `каждый понедельник в 10:00 отчёт` | еженедельно |

Если время не указано («завтра купить хлеб»), бот ставит 9:00. Префиксы «напомни», «напомни мне» и `/remind` тоже понимаются.

## Запуск

1. Получите токен у [@BotFather](https://t.me/BotFather).
2. Склонируйте репозиторий и создайте `.env`:

```bash
git clone https://github.com/proxende1/reminder-bot.git
cd reminder-bot
cp .env.example .env   # впишите BOT_TOKEN
```

### Через Docker

```bash
docker compose up -d --build
```

### Локально

```bash
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m bot
```

## Настройки (`.env`)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `BOT_TOKEN` | — | Токен бота (обязательно) |
| `DB_PATH` | `data/reminders.db` | Файл базы SQLite |
| `TIMEZONE` | `Europe/Moscow` | Часовой пояс для «завтра в 10:00» |
| `CHECK_INTERVAL` | `10` | Как часто проверять созревшие напоминания, сек |

## Как устроено

```
bot/
├── __main__.py    # точка входа: polling + фоновая задача планировщика
├── config.py      # настройки из .env
├── timeparse.py   # разбор русского текста → datetime + повтор (чистые функции)
├── db.py          # SQLite через aiosqlite, время в UTC
├── scheduler.py   # цикл: достаёт созревшие напоминания, шлёт, переносит повторы
├── formatting.py  # «завтра в 10:00», «через 2 ч 5 мин», «каждую пятницу»
├── keyboards.py   # inline-кнопки (CallbackData)
└── handlers.py    # команды, создание напоминаний, колбэки
```

**Планировщик** не держит таймеры в памяти, а раз в `CHECK_INTERVAL` секунд выбирает из БД записи с `remind_at <= now`. Поэтому после перезапуска ничего не теряется. Повторяющиеся напоминания переносятся на следующее срабатывание по «настенному» времени: «каждый день в 9:00» остаётся в 9:00 и после перевода часов. Если пользователь заблокировал бота, его напоминания удаляются.

## Разработка

```bash
pip install -r requirements-dev.txt
pytest          # 90+ тестов
ruff check .
ruff format .
```

Тесты покрывают парсер времени (60+ кейсов, включая невалидные даты и переход на зимнее время), БД, планировщик и сквозные сценарии. Апдейты прогоняются через настоящий диспетчер aiogram с фейковой сессией Telegram API, так что токен и сеть не нужны.
